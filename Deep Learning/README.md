# Deep Learning projects

This folder contains my hands-on deep learning projects built during my early journey into machine learning (started ~2 months ago). Each project explores key concepts of computer vision and neural networks, with both theoretical understanding and practical implementations.

---

# projects

1. Cat vs Dog
- Goal: Train a CNN to classify images as either cat or dog
- Techniques: Convolutional Neural Networks (CNNs), data augmentation, dropout regularization, tune a pretrained model
2. Face Recognition
- Goal: Build a pipeline for face recognition using deep learning
- Techniques: CNN for face embedding, data augmentation, tune a pretrained model, MTCNN for face detection and alignment
3. Depth Estimation
- Goal: Predict depth maps from a single RGB image

 I'm still working on it
