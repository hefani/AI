# Supervised Learning

This folder contains implementations of foundational supervised machine learning algorithms from scratch, applied to real-world datasets (mostly from Kaggle). Each project showcases training, evaluation, and insights from applying algorithms to structured datasets.

---

## Objective

This section is designed to:
- Demonstrate a practical understanding of supervised learning techniques.
- Explore key classification and regression models.
- Apply algorithms on curated Kaggle datasets to strengthen problem-solving and research skills.

---

## Contents

| Algorithm | Description | Application Example |
|----------|-------------|---------------------|
| **Linear Regression** | Predicts continuous outputs by modeling linear relationships. | House price prediction |
| **Logistic Regression** | Performs binary classification using sigmoid activation. | Raisin prediction (Besni/Kecimen) |
| **Softmax Regression** | Extension of logistic regression for multi-class classification. | Personality prediction (Introvert/Ambivert/Extrovert) |
| **Naive Bayes** | Probabilistic classifier using Bayes’ theorem under feature independence assumption. | Email spam classification |
| **k-Nearest Neighbors (k-NN)** | Classifies based on the majority label among the *k* closest samples. | Image and text classification |
| **Support Vector Machine (SVM)** | Finds the optimal hyperplane for classification; includes kernelized variant. |  |
| **Gaussian Discriminant Analysis (GDA)** | A generative model assuming features follow Gaussian distribution within each class. | Personality prediction (Introvert/Ambivert/Extrovert) |
| **Decision Tree** |  | the drug that each patient responded to |

## Datasets

All datasets used in this section are publicly available and sourced from [Kaggle](https://kaggle.com). Each project folder contains:
- A brief dataset description
- Code for data preprocessing, training, and evaluation
- Visualizations (if applicable)

---

## Structure

Each algorithm has its own subfolder, typically containing:
- `model.py` or `main.py`: the core implementation
- `README.md`: a short explanation of the approach and dataset
- `results/`: (optional) visualizations or outputs from the trained models
